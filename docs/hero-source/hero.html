01the admission ladder

A rule may not act until its benign firing rate has been measured.

Four lanes separate non-executable rules, recording, advice and denial. ADVISE and DENY require an exact binomial (Clopper–Pearson) upper limit on how often the rule fires on ordinary traffic. Their gates are not zero, so a promoted rule carries a ceiling on how often it may interrupt you rather than a promise that it never will.

DO_NOT_SHIP
Never executes. The rule is not mechanically runnable.

02what reaches your disk

The matched text is never written. An offset and a hash go in its place.

EVENTA wired tool event on PreToolUse or PostToolUse
→
TRAVERSALEligible string leaves of tool_input or tool_response
→
SCANOne worker per event, each rule compiled once, run against every leaf
→
VERDICTCoverage complete, or it says so and never calls unscanned leaves clean
A completed finding is one JSON line in ~/.claude/agent-defs/findings.jsonl, carrying these fields and no others:
event surface rule_id lane admission path start end text_sha256 truncated
Raw tool text is not logged. A JSON path, a character span and a hash of the leaf stand in for it. The log is local and never enters the model context.
